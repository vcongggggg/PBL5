# PBL5 Smart Parking Control - Design System

## Visual Personality
- **Style**: Professional SaaS Dashboard, Enterprise-grade, Clean, Modern, Functional.
- **Color Palette**: 
    - `Primary`: #3b82f6 (Modern Blue)
    - `Secondary`: #64748b (Slate)
    - `Success`: #22c55e
    - `Warning`: #f59e0b
    - `Danger`: #ef4444
    - `Background`: #f8fafc (Light Gray)
    - `Surface`: #ffffff (White)
    - `Sidebar`: #0f172a (Deep Dark Blue)
- **Typography**: Inter or System Sans-Serif. Clean, readable weights.
- **Components**: Rounded corners (8px-12px), subtle borders, soft shadows, clear visual hierarchy.

## Layout
- **Sidebar**: Fixed left navigation for primary sections.
- **Topbar**: Search, notifications, and user status.
- **Main Content**: Scrollable area with cards for data visualization and controls.
- **Grid**: Responsive 12-column grid system.
